# YouTube: больше видео на главной

Расширение для Chrome. Делает главную страницу YouTube компактнее: узкая колонка по центру, мелкие заголовки, больше видео в ряду и всегда открытая левая панель. Цвета подстраиваются под светлую и тёмную тему.

 Установка

1. Скачайте репозиторий: кнопка **Code**, затем **Download ZIP**, и распакуйте архив.
2. Откройте в Chrome `chrome://extensions`.
3. Включите **Режим разработчика** (справа вверху).
4. Нажмите **Загрузить распакованное расширение** и выберите папку с файлами.
5. Обновите YouTube (F5).

 Настройка

Всё настраивается в файле `style.css`:

- `--ytd-rich-grid-items-per-row` — сколько видео в ряду.
- `max-width` — ширина колонки. Для 5 видео в ряду примерно 1250px, для 6 — 1500px. Значение `none` растягивает колонку на всю ширину экрана.

После правки файла нажмите круглую стрелку у расширения на `chrome://extensions` и обновите страницу YouTube.

 Файлы

- `manifest.json` — описание расширения
- `style.css` — оформление главной страницы
- `content.js` — открывает левую панель при загрузке страницы

Примечание

YouTube периодически меняет разметку, поэтому часть селекторов в `style.css` может перестать работать.
